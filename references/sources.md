# 信息源与博主清单

## 信息搜集优先级

1. **品牌官网产品页**（链接必含、参数权威）：搜索 `"<品牌> <机型> 官网 参数"` 或用 `web_fetch` 直接访问官网产品页。
2. **专业参数库**（交叉核验）：
   - 中关村在线 `detail.zol.com.cn`
   - IT之家 `ithome.com`
   - 太平洋电脑网 `pconline.com.cn`
   - 手机中国 `cnmo.com`
   - 安兔兔（跑分/参数）
3. **官方/发布会新闻稿**（宣传点来源）。
4. **博主测评**（视频为主）。

## 深度影像资料搜集渠道（发布会细节/营销卖点，重要）

影像宣传点与精密工程参数（电机重量、防抖等级、动态范围档位、色彩预设数量、无损变焦倍数等）通常**不会完整出现在基础参数页**，必须从以下渠道专项搜集，避免依赖用户喂料：

1. **官方新闻稿（PR 稿）**：发布会当天发布在品牌官网 Newsroom，含完整技术细节（如"2.6g 云台电机""120 N·m/L 扭矩密度"）。搜索 `"<品牌> <机型> 发布 news 新闻稿"`，或直接访问 `<品牌官网>/global/news/` 检索。
2. **发布会图文实录/汇总帖**：IT之家、中关村在线、太平洋电脑网、腾讯科技等发布会当天发布的"发布会汇总/图文直播"文章，逐条记录发布口径（含"行业首创/首发/第一"等定性表述）。搜索 `"<机型> 发布会 汇总 图文 实录"`。
3. **权威央媒/门户报道**：新华网、人民网、网易、新浪等发布的发布报道，常含精确工程参数（CIPA 防抖等级、动态范围、电机规格、补偿率）。
4. **官方发布会回顾视频**：品牌官方抖音/B 站账号发布的发布会精彩回顾，含高管演讲原话（如"信噪比提升 8dB""内置 11 种 ARRI Look"）。搜索 `"<机型> 发布会 回顾"` 或品牌官方号主页。
5. **专业影像媒体**：色影无忌、影像狗等对影像系统的深度解析文章。

### 深度资料搜集方法
- 至少检索"官方新闻稿"+"发布会汇总"两类，与参数库/官网产品页交叉核验。
- 营销定性表述（行业首创/首发/第一）以官方新闻稿或发布会实录为准；工程参数（防抖等级、动态范围、电机规格）多源一致后再填入。
- 提取的卖点按"行业首创/影像卖点/生态"分类整理进"宣传点"字段；与用户手头资料冲突时，以官方发布口径优先并标注来源。

## 博主测评搜集方法

- 在 B 站/抖音/YouTube 搜索 `"<博主> <机型> 评测"`（可叠加"测评/上手/影像"关键词）。
- 按名单顺序找，优先已发布该机型影像/拍照向测评的博主；找到 2–3 位即可。
- 每条测评记录：博主名 + 视频标题 + 链接 + 平台。
- 若名单内博主均未发布该机型测评，注明"名单内博主暂无该机型测评"，并补充 1–2 条其他高质量测评（如相机评测媒体 DXOMARK、专业科技媒体等）。
