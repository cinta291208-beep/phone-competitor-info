# 字段定义与填写规范

所有字段信息必须来自官网、专业参数库或博主测评等真实来源；查不到填"未公开/待补充"，禁止编造。
单位约定：屏幕尺寸用英寸；分辨率用"宽×高"（如 3200×1440）；亮度用 nit；刷新率/采样率用 Hz；视场角用 °。

## 前置（5 字段）

| 字段 | 填写内容 |
| --- | --- |
| 前置摄像头 | 摄像头数量与类型、传感器型号、像素、光圈、是否支持自动对焦 |
| 照片分辨率 | 前置最大拍照分辨率（如 8192×6144 / 约 5000 万像素） |
| 摄像分辨率 | 前置视频录制最大规格（如 4K60 / 1080P30） |
| 拍摄功能 | 人像模式、美颜、夜景、慢动作、HDR、广角自拍等 |
| 人脸识别 | 是否支持、类型（2D 相机人脸识别 / 3D 结构光） |

## 后置（6 字段）

| 字段 | 填写内容 |
| --- | --- |
| 主摄 | 传感器型号（如 IMX989）、像素、光圈、焦距、光学防抖、传感器尺寸 |
| 长焦 | 变焦倍数（3x/5x/10x）、像素、光圈、是否潜望式 |
| 超广角 | 视场角（°）、像素、光圈 |
| 照片分辨率 | 后置最大拍照分辨率 |
| 摄像分辨率 | 后置视频录制最大规格（如 8K30 / 4K120 / ProRes 等） |
| 拍摄功能 | 夜景、人像、微距、电影模式、RAW、防抖增强、AI 影像等 |

## 屏幕（9 字段）

| 字段 | 填写内容 |
| --- | --- |
| 尺寸 | 对角线英寸（如 6.7 英寸） |
| 分辨率 | 如 3200×1440；注明是否 LTPO 可变刷新率 |
| 色彩 | 色深（如 10bit）、色域（如 DCI-P3）、色彩准确度（ΔE） |
| 类型 | OLED / LTPS / AMOLED 等 |
| 亮度 | 典型亮度与峰值亮度（nit） |
| 护眼 | 高频 PWM 调光（如 2160Hz）、类 DC 调光、莱茵护眼认证等 |
| 显示技术 | LTPO、自适应刷新率（1–120Hz）、HDR 支持等 |
| 保护玻璃材质 | 康宁大猩猩（第几代）/ 昆仑玻璃 / 龙晶玻璃 / 微晶玻璃等 |
| 触控 | 触控采样率、屏幕刷新率 |

## 其他（4 字段）

| 字段 | 填写内容 |
| --- | --- |
| 宣传点 | 发布会/官网核心卖点（影像优先，兼顾屏幕与整体） |
| 官网介绍链接 | 品牌官网产品页 URL（**必填**） |
| 博主测评链接 | 各博主测评视频/文章链接，注明博主名 + 平台 |
| 补充信息 | 其他重要信息（起售价、配色、发布地区、待确认事项等） |
